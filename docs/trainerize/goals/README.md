# Trainerize Photos, Goals & Accomplishments — Frontend Integration

> **Audience:** Frontend developers consuming the Apex Patient Portal backend.
> **Scope:** Tier A client APIs under `/trainerize/me/...` (June 2026 implementation).
> **Status:** Shipped on backend.

---

## Base conventions

| Item | Value |
|---|---|
| Base URL prefix | `/api` |
| Auth | Session cookie `apex_access_token` — send with `credentials: 'include'` |
| Success envelope | `{ "success": true, "data": ... }` |
| Error envelope | `{ "success": false, "message": "..." }` |

---

## Prerequisites

1. User must be logged in (valid Apex session).
2. User must have a **linked Trainerize client account**.

```
GET /api/trainerize/me/link
```

If `data` is `null`, show Trainerize onboarding before calling these endpoints. Unlinked users receive **`404`**.

---

## Endpoints

### Photos

| Doc | Method | Path |
|---|---|---|
| [list-photos.md](./list-photos.md) | `GET` | `/trainerize/me/photos` |
| [upload-photo.md](./upload-photo.md) | `POST` | `/trainerize/me/photos` |

`photos/getByID` is **not** exposed — no binary download proxy yet.

### Goals

| Doc | Method | Path |
|---|---|---|
| [list-goals.md](./list-goals.md) | `GET` | `/trainerize/me/goals/list` |
| [goal-detail.md](./goal-detail.md) | `GET` | `/trainerize/me/goals/detail` |
| [goal-add.md](./goal-add.md) | `POST` | `/trainerize/me/goals` |
| [goal-set.md](./goal-set.md) | `PUT` | `/trainerize/me/goals` |
| [goal-progress.md](./goal-progress.md) | `PUT` | `/trainerize/me/goals/progress` |
| [goal-delete.md](./goal-delete.md) | `DELETE` | `/trainerize/me/goals` |

List uses **`/goals/list`** (not `/goals`) to avoid collision with mutating routes on `/goals`.

### Accomplishments (read-only)

Accomplishments are **auto-generated by Trainerize** — no create/update/delete APIs.

| Doc | Method | Path |
|---|---|---|
| [list-accomplishments.md](./list-accomplishments.md) | `GET` | `/trainerize/me/accomplishments` |
| [accomplishment-stats.md](./accomplishment-stats.md) | `GET` | `/trainerize/me/accomplishments/stats` |

Register **`/accomplishments/stats` before `/accomplishments`** on backend (already done).

## Common errors

| HTTP | When |
|---|---|
| `401` | Missing or invalid session |
| `404` | Trainerize account not linked |
| `400` | Validation error (Zod) |
| `502` | Trainerize Partner API failure |
